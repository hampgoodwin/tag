Lesson 07: Game States, Main Menu, Esc Pause & Restart/Quit

Time to bring everything together into a complete, polished game loop! You will boot into a Main Menu (single Start button), let the player press Esc anytime to freeze physics and open the Pause Menu (Restart & Quit, or Esc again to resume), transition to Game Over when eliminated, and optionally organize your code into clean Rust modules ready for custom maps!

State Machine Design

  • Top-level AppState: MainMenu → Playing → GameOver
  • Child SubStates PlayState: Running ↔ Paused
  • Freezing FixedUpdate physics automatically via .run_if(...)

Bevy 0.20 Concepts

  • DespawnOnExit(State) for zero-leak Restart cleanup
  • Modern UI buttons via .observe(|_: On<PointerClick>, ...|)
  • Quitting cleanly via MessageWriter<AppExit>

Rust Concepts

  • Observer closures (|trigger: On<...>| { ... })
  • Trait bounds required by States (Eq, Hash, Clone)
  • Splitting a growing file into Rust modules (mod & Plugin)

1. Hierarchical Game States: AppState + PlayState

Why use two state enums instead of putting Paused inside AppState? Think about what happens when you press Esc mid-match: you want the arena, player, NPCs, and HUD to remain visible on screen in the background while frozen, and only despawn when leaving the match!

Bevy's SubStates was built for this exact pattern:

  • AppState (MainMenu, Playing, GameOver): Owns the lifetime of match entities. Every arena wall, square, and HUD node carries DespawnOnExit(AppState::Playing). Pausing does not exit AppState::Playing, so all squares stay right where they are!
  • PlayState (Running, Paused): Annotated with #[source(AppState = AppState::Playing)]. It exists only while AppState::Playing is active, starts in Running automatically, and gating your physics systems with .run_if(in_state(PlayState::Running)) freezes every velocity and timer the instant you pause!

Bevy 0.20 Modern UI Buttons: Pointer Observers!

In Bevy 0.20, the legacy bevy::ui::Button and Interaction polling components were deprecated in favor of Picking Observers (included in DefaultPlugins!). Any styled Node becomes an interactive button simply by attaching .observe(...) callbacks for PointerEnter, PointerLeave, and PointerClick—and pointer events automatically bubble up from the child Text label to your button Node!

Step 1

Define AppState & PlayState, and Scope Match Entities

  • Define AppState deriving States, Default, Clone, Copy, PartialEq, Eq, Hash, Debug with #[default] MainMenu, Playing, and GameOver.
  • Define PlayState deriving SubStates, Default, Clone, Copy, PartialEq, Eq, Hash, Debug with #[source(AppState = AppState::Playing)], #[default] Running, and Paused.
  • Register .init_state::<AppState>().add_sub_state::<PlayState>() on App (right after DefaultPlugins!).
  • Keep setup_camera in Startup (one permanent camera for the whole app!), and move (reset_match_resources, spawn_arena, spawn_player, spawn_npcs, spawn_hud) to OnEnter(AppState::Playing)!
  • Add DespawnOnExit(AppState::Playing) to every entity spawned in spawn_arena, spawn_player, spawn_npcs, and the root node of spawn_hud!
Step 1 Reference Solution 
#[derive(States, Default, Clone, Copy, PartialEq, Eq, Hash, Debug)]
pub enum AppState {
    #[default]
    MainMenu,
    Playing,
    GameOver,
}

#[derive(SubStates, Default, Clone, Copy, PartialEq, Eq, Hash, Debug)]
#[source(AppState = AppState::Playing)]
pub enum PlayState {
    #[default]
    Running,
    Paused,
}

fn reset_match_resources(mut commands: Commands) {
    commands.insert_resource(RoundPhase::new_active());
    commands.insert_resource(MatchOutcome::Ongoing);
}

Remember to attach DespawnOnExit(AppState::Playing) to your match entities (floor, walls, player, NPCs, and root HUD node), e.g.:

// Example on spawn_player (do the same on floor, walls, NPCs, and root HUD Node!):
commands.spawn((
    DespawnOnExit(AppState::Playing),
    Character,
    Player,
    // ... rest of components ...
));
Rust Concept: Why Does #[derive(States)] Require Eq + Hash + Clone?
  • Internally, Bevy stores transition schedules like OnEnter(AppState::Playing) in a HashMap keyed by state value! In Rust, a HashMap key must implement Hash and Eq (reflexive equality), and Bevy clones the tiny enum variant during transition events.
Step 2

Build Reusable button_bundle & style_button_hover Helpers

Avoid repeating styling and hover logic across your Start, Restart, and Quit buttons! Write two tiny helpers: button_bundle(label: impl Into<String>) -> impl Bundle for consistent layout/text (marking the inner text Pickable::IGNORE so pointer hits target the button cleanly), and style_button_hover to highlight on PointerEnter / PointerLeave!

Step 2 Reference Solution 
const BTN_BG: Color = Color::srgb(0.14, 0.18, 0.25);
const BTN_HOVER_BG: Color = Color::srgb(0.24, 0.30, 0.42);
const BTN_BORDER: Color = Color::srgb(0.35, 0.43, 0.56);

fn style_button_hover(entity_cmds: &mut EntityCommands) {
    entity_cmds
        .observe(|enter: On<PointerEnter>, mut bgs: Query<&mut BackgroundColor>| {
            if let Ok(mut bg) = bgs.get_mut(enter.entity) {
                bg.0 = BTN_HOVER_BG;
            }
        })
        .observe(|leave: On<PointerLeave>, mut bgs: Query<&mut BackgroundColor>| {
            if let Ok(mut bg) = bgs.get_mut(leave.entity) {
                bg.0 = BTN_BG;
            }
        });
}

fn button_bundle(label: impl Into<String>) -> impl Bundle {
    (
        Node {
            width: Val::Px(220.0),
            height: Val::Px(48.0),
            justify_content: JustifyContent::Center,
            align_items: AlignItems::Center,
            border: UiRect::all(Val::Px(1.5)),
            border_radius: BorderRadius::all(Val::Px(8.0)),
            ..default()
        },
        BackgroundColor(BTN_BG),
        BorderColor::all(BTN_BORDER),
        children![(
            Text::new(label),
            TextFont::from_font_size(18.0),
            TextColor(Color::srgb(0.95, 0.97, 1.0)),
            Pickable::IGNORE,
        )],
    )
}
Rust Concepts Inside This Snippet (Edition 2024 Gotcha!):
  • Why label: impl Into<String> instead of label: &str? In Rust Edition 2024, a return type of -> impl Bundle automatically captures any input borrow lifetimes (impl Bundle + use<'_>). If you took label: &str, passing a non-'static local string slice into commands.spawn(button_bundle(&s)) would fail because ECS components must be 'static! Accepting impl Into<String> owns the label with zero captured lifetimes and accepts both "Start" and String!
  • Return-Position impl Bundle: The tuple returned by button_bundle has a long nested macro type from children![]. Writing -> impl Bundle lets the compiler infer the exact concrete type while promising callers it implements Bundle.
  • Observer Closures (|enter: On<PointerEnter>, ...|): Just like regular Bevy systems, closures passed to .observe(...) can request any ECS parameters (Query, ResMut, MessageWriter)!
Step 3

Implement Main Menu (Start), Esc Pause (Restart / Quit) & Game Over

Now wire all three screens to match your exact specification:

  • Main Menu (OnEnter(AppState::MainMenu)): Full-screen centered column with game title and only one button: Start. Clicking Start calls next_state.set(AppState::Playing).
  • Esc Toggle (Update while in_state(AppState::Playing)): When keyboard.just_pressed(KeyCode::Escape) fires, match on play_state.get():
    • PlayState::Running → next_play_state.set(PlayState::Paused)
    • PlayState::Paused → next_play_state.set(PlayState::Running) (resumes!)
  • Pause Menu (OnEnter(PlayState::Paused)): Semi-transparent backdrop over the frozen arena with only two buttons: Restart and Quit (plus a subtle hint text that pressing Esc resumes):
    • Restart: Calls next_play_state.set(PlayState::Running); next_app_state.set(AppState::Playing);. In Bevy 0.20, NextState::set runs same-state exit + enter transitions, so DespawnOnExit(AppState::Playing) wipes the old match and OnEnter(AppState::Playing) spawns a brand-new match!
    • Quit: Calls exit.write(AppExit::Success); via MessageWriter<AppExit>.
  • Game Over Transition & Screen (AppState::GameOver): In update_round_phase, when MatchOutcome::PlayerEliminated (or PlayerWon) triggers, call next_app_state.set(AppState::GameOver) and show Restart & Quit!

fn spawn_main_menu(mut commands: Commands) {
    let root = commands
        .spawn((
            DespawnOnExit(AppState::MainMenu),
            Node {
                width: Val::Percent(100.0),
                height: Val::Percent(100.0),
                flex_direction: FlexDirection::Column,
                justify_content: JustifyContent::Center,
                align_items: AlignItems::Center,
                row_gap: Val::Px(24.0),
                ..default()
            },
            BackgroundColor(Color::srgb(0.05, 0.07, 0.10)),
            children![
                (
                    Text::new("TAG"),
                    TextFont::from_font_size(52.0),
                    TextColor(Color::srgb(0.97, 0.51, 0.40)),
                ),
                (
                    Text::new("WASD / Arrows to move (1.2x speed)  •  Avoid holding IT > 10s"),
                    TextFont::from_font_size(15.0),
                    TextColor(Color::srgb(0.55, 0.60, 0.68)),
                ),
            ],
        ))
        .id();

    let mut start_btn = commands.spawn((ChildOf(root), button_bundle("Start")));
    style_button_hover(&mut start_btn);
    start_btn.observe(|click: On<PointerClick>, mut next_state: ResMut<NextState<AppState>>| {
        if click.button == PointerButton::Primary {
            next_state.set(AppState::Playing);
        }
    });
}

fn toggle_pause_on_escape(
    keyboard: Res<ButtonInput<KeyCode>>,
    play_state: Res<State<PlayState>>,
    mut next_play_state: ResMut<NextState<PlayState>>,
) {
    if keyboard.just_pressed(KeyCode::Escape) {
        match play_state.get() {
            PlayState::Running => next_play_state.set(PlayState::Paused),
            PlayState::Paused => next_play_state.set(PlayState::Running),
        }
    }
}

fn spawn_pause_menu(mut commands: Commands) {
    let root = commands
        .spawn((
            DespawnOnExit(PlayState::Paused),
            GlobalZIndex(10), // Guarantees the pause backdrop renders above the HUD
            Node {
                position_type: PositionType::Absolute,
                width: Val::Percent(100.0),
                height: Val::Percent(100.0),
                flex_direction: FlexDirection::Column,
                justify_content: JustifyContent::Center,
                align_items: AlignItems::Center,
                row_gap: Val::Px(14.0),
                ..default()
            },
            BackgroundColor(Color::srgba(0.03, 0.04, 0.07, 0.78)),
            children![
                (
                    Text::new("PAUSED"),
                    TextFont::from_font_size(38.0),
                    TextColor(Color::srgb(0.95, 0.97, 1.0)),
                ),
                (
                    Text::new("Press Esc to resume"),
                    TextFont::from_font_size(14.0),
                    TextColor(Color::srgb(0.55, 0.62, 0.70)),
                ),
            ],
        ))
        .id();

    let mut restart_btn = commands.spawn((ChildOf(root), button_bundle("Restart")));
    style_button_hover(&mut restart_btn);
    restart_btn.observe(
        |click: On<PointerClick>,
         mut next_play: ResMut<NextState<PlayState>>,
         mut next_app: ResMut<NextState<AppState>>| {
            if click.button == PointerButton::Primary {
                next_play.set(PlayState::Running);
                next_app.set(AppState::Playing);
            }
        },
    );

    let mut quit_btn = commands.spawn((ChildOf(root), button_bundle("Quit")));
    style_button_hover(&mut quit_btn);
    quit_btn.observe(|click: On<PointerClick>, mut exit: MessageWriter<AppExit>| {
        if click.button == PointerButton::Primary {
            exit.write(AppExit::Success);
        }
    });
}

fn update_round_phase(
    mut commands: Commands,
    time: Res<Time>,
    mut phase: ResMut<RoundPhase>,
    mut outcome: ResMut<MatchOutcome>,
    mut next_app_state: ResMut<NextState<AppState>>,
    characters: Query<(Entity, Option<&Player>, Option<&IsIt>), With<Character>>,
) {
    // ... inside RoundPhase::ActiveTag when timer finishes:
    if was_player.is_some() {
        *outcome = MatchOutcome::PlayerEliminated;
        next_app_state.set(AppState::GameOver);
        return;
    }
    // ... and when survivors.len() <= 1:
    if survivors.len() <= 1 {
        *outcome = MatchOutcome::PlayerWon;
        next_app_state.set(AppState::GameOver);
        return;
    }
}
Bevy Relationship Gem: ChildOf(root)
  • Look at how clean commands.spawn((ChildOf(root), button_bundle("Start"))) is! Capturing let root = commands.spawn(...).id(); and attaching ChildOf(root) on child buttons makes them children of root—so when root despawns via DespawnOnExit, all its child buttons and grandchildren text nodes despawn automatically too!

Final App Schedule Wiring & Optional Module Layout

Gate your FixedUpdate simulation chain with .run_if(in_state(PlayState::Running)) and your gameplay Update systems with .run_if(in_state(AppState::Playing))!

Step 4 Reference Solution (Complete main() Registration) 
fn main() {
    App::new()
        .add_plugins(DefaultPlugins.set(WindowPlugin {
            primary_window: Some(Window {
                title: "Tag".into(),
                resolution: (1000, 720).into(),
                ..default()
            }),
            ..default()
        }))
        .init_state::<AppState>()
        .add_sub_state::<PlayState>()
        .insert_resource(ClearColor(Color::srgb(0.05, 0.07, 0.10)))
        .insert_resource(ArenaBounds {
            half_size: Vec2::new(ARENA_WIDTH * 0.5, ARENA_HEIGHT * 0.5),
        })
        .init_resource::<MatchOutcome>()
        .add_message::<CollisionMessage>()
        // Permanent 2D camera
        .add_systems(Startup, setup_camera)
        // State entry screens & match setup
        .add_systems(OnEnter(AppState::MainMenu), spawn_main_menu)
        .add_systems(
            OnEnter(AppState::Playing),
            (
                reset_match_resources,
                spawn_arena,
                spawn_player,
                spawn_npcs,
                spawn_hud,
            ),
        )
        .add_systems(OnEnter(PlayState::Paused), spawn_pause_menu)
        .add_systems(OnEnter(AppState::GameOver), spawn_game_over_menu)
        // Physics & round rules — ONLY tick when unpaused in Playing!
        .add_systems(
            FixedUpdate,
            (
                tick_tag_cooldowns,
                player_input,
                npc_steering,
                apply_velocity,
                resolve_character_collisions,
                confine_to_arena,
                handle_tag_transfers,
                update_round_phase,
            )
                .chain()
                .run_if(in_state(PlayState::Running)),
        )
        // Visuals, HUD & Esc toggle while in Playing
        .add_systems(
            Update,
            (toggle_pause_on_escape, sync_character_colors, update_hud)
                .run_if(in_state(AppState::Playing)),
        )
        .run();
}

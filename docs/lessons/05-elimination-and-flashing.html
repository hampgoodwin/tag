Lesson 05: 10s Elimination Clock, Random Selection & 5s Flash Phase

Now let's give Tag real stakes: if any character holds 'it' for longer than 10 seconds, they are eliminated! Then a random surviving character flashes for 5 seconds before becoming the new 'it'—and if the main player is eliminated, the match ends.

Game Rules & Timing

  • 10.0s per-holder elimination countdown (resets on tag transfer!)
  • 5.0s random survivor telegraph/flashing grace phase
  • Detecting Player elimination vs. Last-Survivor victory

Bevy 0.20 Concepts

  • Timer::from_seconds(..., TimerMode::Once) vs Repeating
  • commands.entity(e).despawn()
  • Resource-driven phase machines

Rust Concepts

  • Algebraic data types (enum variants carrying fields!)
  • Adding external crates (rand = "0.10")
  • Dereferencing smart pointers (ResMut<T>) with match &mut *phase

1. Making Invalid States Unrepresentable with a Rust enum

In many languages, you might model the round clock with a struct full of booleans and nullable fields: is_flashing: bool, pending_entity: Option<Entity>, it_timer: Timer, flash_timer: Timer. That invites bugs: what if is_flashing is true while pending_entity is None, or both timers tick at once?

In Rust, an enum is a sum type (tagged union)—each variant can hold its own dedicated fields! A match is either in ActiveTag (counting down 10s while someone has IsIt) or in FlashingNext (counting down 5s while a randomly chosen target flashes): 

#[derive(Resource)]
pub enum RoundPhase {
    ActiveTag {
        timer: Timer, // 10.0s Once
    },
    FlashingNext {
        target: Entity,
        timer: Timer,      // 5.0s Once
        flash_tick: Timer, // 0.14s Repeating strobe
        flash_on: bool,
    },
}

Update handle_tag_transfers to accept mut phase: ResMut<RoundPhase> and reset the 10s timer right before break;:

fn handle_tag_transfers(
    mut commands: Commands,
    mut collisions: MessageReader<CollisionMessage>,
    mut phase: ResMut<RoundPhase>,
    it_query: Query<Entity, With<IsIt>>,
    cooldowns: Query<&TagCooldown>,
) {
    let Some(it_entity) = it_query.iter().next() else {
        return;
    };

    for &CollisionMessage(a, b) in collisions.read() {
        let (old_it, new_it) = if a == it_entity {
            (a, b)
        } else if b == it_entity {
            (b, a)
        } else {
            continue;
        };

        if cooldowns.contains(old_it) || cooldowns.contains(new_it) {
            continue;
        }

        commands
            .entity(old_it)
            .remove::<IsIt>()
            .insert(TagCooldown(Timer::from_seconds(TAG_COOLDOWN_SECS, TimerMode::Once)));
        commands.entity(new_it).insert(IsIt);

        if let RoundPhase::ActiveTag { timer } = &mut *phase {
            timer.reset();
        }
        break;
    }
}
Rust Concept: Why &mut *phase?
  • phase has wrapper type ResMut<RoundPhase>, which implements DerefMut<Target = RoundPhase>. Writing *phase dereferences through ResMut to the underlying RoundPhase, and &mut borrows its fields mutably instead of trying to move the enum out of the resource!
Step 3

Write update_round_phase (10s Elimination + Random 5s Flash)

Create a system update_round_phase that ticks ResMut<RoundPhase> when *outcome == MatchOutcome::Ongoing:

  • In RoundPhase::ActiveTag { timer }: If timer.tick(time.delta()).just_finished():
    1. Find the current IsIt entity from characters: Query<(Entity, Option<&Player>, Option<&IsIt>), With<Character>>.
    2. Despawn that entity (commands.entity(it_entity).despawn();).
    3. If that entity had Player, set *outcome = MatchOutcome::PlayerEliminated; and return!
    4. Collect all remaining surviving entities (e != it_entity) into a Vec<Entity>.
    5. If survivors.len() <= 1, the player is the sole survivor—set *outcome = MatchOutcome::PlayerWon; and return!
    6. Otherwise pick let chosen = survivors[rand::random_range(0..survivors.len())]; and set *phase = RoundPhase::FlashingNext { target: chosen, timer: Timer::from_seconds(FLASH_SECS, TimerMode::Once), flash_tick: Timer::from_seconds(0.14, TimerMode::Repeating), flash_on: true };!
  • In RoundPhase::FlashingNext { target, timer, flash_tick, flash_on }:
    1. If flash_tick.tick(time.delta()).just_finished(), toggle *flash_on = !*flash_on.
    2. If timer.tick(time.delta()).just_finished(), promote target with commands.entity(*target).insert(IsIt); and set *phase = RoundPhase::new_active();!
  • Visual Strobe: Update sync_character_colors to read Res<RoundPhase> and Entity—when FlashingNext has entity == target && flash_on, set sprite.color = Color::srgb(1.0, 0.88, 0.32) (bright warning gold/white)! (Bonus: in npc_steering, you can also treat FlashingNext.target as the threat position so NPCs scatter during the 5-second warning!)

fn update_round_phase(
    mut commands: Commands,
    time: Res<Time>,
    mut phase: ResMut<RoundPhase>,
    mut outcome: ResMut<MatchOutcome>,
    characters: Query<(Entity, Option<&Player>, Option<&IsIt>), With<Character>>,
) {
    if *outcome != MatchOutcome::Ongoing {
        return;
    }

    let dt = time.delta();

    match &mut *phase {
        RoundPhase::ActiveTag { timer } => {
            if timer.tick(dt).just_finished() {
                // Find who held 'it' too long
                let Some((eliminated, was_player, _)) =
                    characters.iter().find(|&(_, _, is_it)| is_it.is_some())
                else {
                    return;
                };

                commands.entity(eliminated).despawn();

                if was_player.is_some() {
                    *outcome = MatchOutcome::PlayerEliminated;
                    println!("GAME OVER — You were eliminated!");
                    return;
                }

                let survivors: Vec<Entity> = characters
                    .iter()
                    .filter(|&(e, _, _)| e != eliminated)
                    .map(|(e, _, _)| e)
                    .collect();

                if survivors.len() <= 1 {
                    *outcome = MatchOutcome::PlayerWon;
                    println!("VICTORY — You are the last square standing!");
                    return;
                }

                let next_idx = rand::random_range(0..survivors.len());
                let chosen = survivors[next_idx];

                *phase = RoundPhase::FlashingNext {
                    target: chosen,
                    timer: Timer::from_seconds(FLASH_SECS, TimerMode::Once),
                    flash_tick: Timer::from_seconds(0.14, TimerMode::Repeating),
                    flash_on: true,
                };
            }
        }
        RoundPhase::FlashingNext {
            target,
            timer,
            flash_tick,
            flash_on,
        } => {
            if flash_tick.tick(dt).just_finished() {
                *flash_on = !*flash_on;
            }
            if timer.tick(dt).just_finished() {
                let next_it = *target;
                commands.entity(next_it).insert(IsIt);
                *phase = RoundPhase::new_active();
            }
        }
    }
}

fn sync_character_colors(
    phase: Res<RoundPhase>,
    mut query: Query<(Entity, &mut Sprite, Option<&Player>, Option<&IsIt>), With<Character>>,
) {
    let flashing_target = match &*phase {
        RoundPhase::FlashingNext { target, flash_on: true, .. } => Some(*target),
        _ => None,
    };

    for (entity, mut sprite, player, is_it) in &mut query {
        if Some(entity) == flashing_target {
            sprite.color = Color::srgb(1.0, 0.88, 0.32); // Flashing gold warning!
            continue;
        }
        sprite.color = match (is_it.is_some(), player.is_some()) {
            (true, true) => Color::srgb(1.0, 0.45, 0.20),
            (true, false) => Color::srgb(0.95, 0.26, 0.26),
            (false, true) => Color::srgb(0.30, 0.67, 0.97),
            (false, false) => Color::srgb(0.41, 0.86, 0.49),
        };
    }
}

Rust Concepts Inside This Snippet:
  • Borrow Lifetimes Across Enum Replacement: Look at let next_it = *target; right before *phase = RoundPhase::new_active();. Because target is a mutable reference into *phase, copying out the Copy Entity ID first ends the borrow of target so Rust lets you overwrite *phase cleanly on the next line!
  • Matching by Reference (match &*phase): RoundPhase contains non-Copy Timer fields, so matching &*phase borrows fields by reference (letting you dereference *target cleanly) without risking accidental moves!
  • Struct Rest Pattern (..): In RoundPhase::FlashingNext { target, flash_on: true, .. }, the .. ignores timer and flash_tick while matching only when flash_on is literally true!
  • Edition 2024 Let-Chains: if let Some(...) = threat && threat_entity != entity combines pattern matching and boolean guards into one flat if statement!

What You Will Build

By the end of Lesson 07, your cargo run binary will boot into a Main Menu and run a crisp, physics-driven top-down game of Tag:

2D Physics Engine

  • Fixed-timestep integration (FixedUpdate)
  • Normalized 8-way player velocity at 1.2× speed
  • NPC chase/flee/wall steering at 1.0× speed
  • AABB overlap, Minimum Translation Vector (MTV) separation & elastic bounce impulses

Tag & Elimination Loop

  • Collision-triggered IsIt transfer + anti-ping-pong cooldown
  • 10s elimination clock—hold 'it' too long and you're despawned
  • Random next survivor flashes for 5s before becoming 'it'
  • Game Over if the main player is eliminated (or Victory if last standing!)

UI & State Machine

  • Boot into Main Menu with a single Start button
  • Live HUD timer tracking the 10s / 5s clocks
  • Press Esc anytime to freeze physics & open the Pause Menu (Esc again to resume)
  • Clean Restart & Quit transitions via DespawnOnExit
